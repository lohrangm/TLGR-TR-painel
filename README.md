# TLGR-TR-painel

Arquivo de distribuicao do userscript **Gestor TLGR - Painel** (Tampermonkey, roda dentro do web.telegram.org).

Este repositorio guarda SO o `painel_telegram.user.js` gerado. Ele e publico porque o Tampermonkey confere atualizacoes
pelo link raw abaixo sem autenticacao. O codigo-fonte fica em outro repositorio, privado.

Link de instalacao e de atualizacao automatica:

https://raw.githubusercontent.com/lohrangm/TLGR-TR-painel/main/painel_telegram.user.js

Nao editar o arquivo aqui: ele e gerado por `painel_build/montar_userscript.mjs` no repositorio do codigo e copiado para ca.
